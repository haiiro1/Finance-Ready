# HU-0112 - Aplicar el modelo visual a Prestamos y deudas

## Objetivo

Aplicar en `/prestamos-deudas` el patron visual de HU-0109 para representar el futuro seguimiento de obligaciones, cuotas y prestamos entre personas.

## Criterios de aceptacion

- [ ] `/prestamos-deudas` usa el lenguaje visual compartido.
- [ ] Deudas pendientes usan warning amber y atrasos danger rose solo con etiquetas explicitas.
- [ ] No se muestran capital, intereses, cuotas o saldos ficticios como datos reales.
- [ ] El estado vacio diferencia obligaciones propias y prestamos entre personas sin implementar flujos.
- [ ] La vista funciona en mobile, desktop y ambos temas.
- [ ] No se agregan calculos, CRUD ni endpoints.

## Paso 2 - Implementacion visual

1. Reutilizar la composicion compartida sin duplicar tokens.
2. Explicar brevemente el alcance futuro de cuotas, vencimientos y prestamos personales.
3. Mantener visibles las diferencias conceptuales sin inventar estados financieros.
4. No diseñar tablas densas vacias ni controles que aparenten estar habilitados.
