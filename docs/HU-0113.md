# HU-0113 - Aplicar el modelo visual a Suscripciones

## Objetivo

Aplicar en `/suscripciones` el patron visual de HU-0109 para el futuro control de recurrencias, participantes y pagos compartidos.

## Criterios de aceptacion

- [ ] `/suscripciones` mantiene la identidad visual del shell.
- [ ] Proximas renovaciones usan warning amber y estados activos usan teal solo con etiquetas claras.
- [ ] No se presentan precios, fechas, participantes o recurrencias ficticias como reales.
- [ ] El estado vacio comunica el alcance futuro sin aparentar funcionalidad disponible.
- [ ] Funciona en mobile, desktop, claro y oscuro.
- [ ] No se agregan formularios, recurrencias, divisiones de costo ni endpoints.
