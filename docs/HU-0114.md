# HU-0114 - Aplicar el modelo visual a Reportes

## Objetivo

Aplicar en `/reportes` el patron visual de HU-0109 para presentar el futuro dominio de analisis, costos financieros y proyecciones sin generar resultados ficticios.

## Criterios de aceptacion

- [ ] `/reportes` usa el sistema visual compartido.
- [ ] Proyecciones usan indigo y estados financieros conservan la semantica del Design System v1.
- [ ] No se muestran graficos, porcentajes, tendencias ni montos inventados como resultados reales.
- [ ] El estado vacio explica que los reportes dependeran de datos registrados.
- [ ] La vista funciona en mobile, desktop, claro y oscuro.
- [ ] No se agregan librerias de graficos, calculos ni endpoints.
