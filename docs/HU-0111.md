# HU-0111 - Aplicar el modelo visual a Bancos y tarjetas

## Objetivo

Aplicar en `/bancos-tarjetas` el patron visual de HU-0109 para anticipar el dominio de bancos, tarjetas, cupos, ciclos y fechas de pago sin simular informacion real.

## Criterios de aceptacion

- [ ] `/bancos-tarjetas` es consistente con el shell y el Design System v1.
- [ ] Ciclos y proximos vencimientos usan warning amber; atrasos usan danger rose solo cuando el estado este explicitamente identificado.
- [ ] No se mezclan monedas ni se presentan cupos o deudas ficticias como reales.
- [ ] La vista incluye un estado vacio claro y accesible.
- [ ] Funciona en mobile, desktop, claro y oscuro.
- [ ] No se implementan tarjetas, CRUD, calculos ni endpoints.

## Paso 2 - Implementacion visual

1. Reutilizar encabezado y estado vacio del patron compartido.
2. Comunicar el alcance futuro: bancos, tarjetas, cupos y ciclos.
3. Mantener fechas, monedas y estados como conceptos etiquetados, nunca como datos inventados.
4. Evitar una representacion decorativa de tarjetas que parezca funcional.
